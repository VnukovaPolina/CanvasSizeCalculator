# Вышивальный помощник - pet-проект, реализованный в рамках моего хобби
Приложение под Android - карманный помощник вышивающих рукодельниц. Предоставляет следующие возможности:
1. Расчет размера готовой вышивки на всех основных каунтах канвы Аида (вводятся размеры вышивки в крестиках)
2. Расчет расхода нитей в зависимости от техники вышивания 
3. Таймер вышивания с напоминаниями о разминке
4. Настройки: смена темы между светлой и темной, включение и отключение уведомлений таймера

## 🛠️ Технологии  
- Язык: **Kotlin**  
- Архитектура: **MVVM**  
- Библиотеки:  
  - **Hilt** 
- Сборка: **Gradle**
- **Jetpack Compose**
